# Temperature Converter (CLI)

A simple, lightweight, and interactive command-line interface (CLI) program written in Python to convert temperatures between Fahrenheit and Celsius.

## Features

- **Interactive Menu:** Clean and centered text layout for an intuitive user experience.
- **Bi-directional Conversion:** 
  - Fahrenheit ($°F$) to Celsius ($°C$)
  - Celsius ($°C$) to Fahrenheit ($°F$)
- **Robust Error Handling:** Validates user inputs using `try-except` blocks to prevent crashes on invalid entries.
- **Formatted Outputs:** Results are neatly displayed with 2 decimal places of precision.

## Requirements

- Python 3.10 or higher (required for `match-case` statement support).

## Usage

When you run the script, you will see the following menu:

----------------------------------------
   press F for Fahrenheit to Celsius    
   press C for Celsius to Fahrenheit    
----------------------------------------
            press Q for quit            
----------------------------------------
  select the action you want to perform.
  

Type F to convert Fahrenheit to Celsius.

Type C to convert Celsius to Fahrenheit.

Type Q to exit the program.
